## 2024-05-18 - Standardized Interactive Keypad Button Utilities
**Learning:** Custom keypads without standard button interaction utilities feel unresponsive and lack accessibility. Adding `touch-manipulation` (for mobile responsiveness), `active:scale-95` (for tactile feedback), `focus-visible:ring-2 focus-visible:ring-primary` (for keyboard navigation), and explicitly defining `aria-label` for non-alphanumeric or icon-only keys (`DEL` -> "Delete", `.` -> "Decimal point") significantly improves the micro-UX and accessibility. It also brings the keypad buttons inline with the overall design system which uses `rounded-2xl` for large interactive areas.
**Action:** Always apply this standard set of utilities (`rounded-2xl`, `touch-manipulation`, `active:scale-95`, `focus-visible:ring-2`, `focus-visible:ring-primary`, `focus:outline-none`) and explicit `aria-label` attributes to custom grid keypads for consistent and accessible interactions.
