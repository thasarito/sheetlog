## 2025-04-19 - Keypad Accessibility & Interaction Enhancements
**Learning:** Icon-only keys (like 'Delete' via `DEL`) and punctuation keys (like `.`) lack semantic meaning for screen readers. Using `focus` on these elements also fails to provide proper keyboard navigation feedback by default unless specific Tailwind focus classes are used. Furthermore, mobile interactions on such keys benefit from immediate tactile feedback.
**Action:** When working with repetitive functional components like `Keypad`, explicitly map non-alphanumeric keys to descriptive `aria-label`s. Ensure standard interaction states (`rounded-2xl`, `touch-manipulation`, `active:scale-95`, `focus-visible:ring-2`, `focus-visible:ring-primary`, `focus:outline-none`) are always applied to primary actionable elements for both mobile tap feel and keyboard accessibility. Use Playwright's `page.evaluate` to reliably click keys when standard `.click()` behavior is obscured or flaky in demo containers.
