## 2024-05-11 - Custom Button Structure Accessibility Focus States
**Learning:** Adding custom button structures often lacks default keyboard navigation (`Enter` / `Space` mapping) and `focus-visible` states, reducing screen reader access and navigation mapping for visually impaired users. Keypad values specifically can lack context for screen reader users when reading "DEL" or "." versus "Delete" and "Decimal point".
**Action:** When implementing interactive non-standard button structures mapping custom events (or when styling removes default focus states), explicitly add keyboard event handlers (like `.onKeyDown` for `Enter`/`Space`) and explicitly add `focus-visible` styling using Tailwind (e.g., `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2`).
