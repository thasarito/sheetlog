## 2024-04-23 - Keypad Button Accessibility & Touch Interactions
**Learning:** Icon-only buttons (like the `Delete` key) within standard functional components (like `Keypad`) often lack proper `aria-label`s, rendering them inaccessible to screen readers. Furthermore, interactive number pads on mobile require clear tactile feedback and visual states (focus rings) to support non-mouse inputs.
**Action:** When auditing custom components mapped from simple string arrays (like `KEYS = ["1", "2", "3", "...", "DEL"]`), explicitly add conditional `aria-label`s for non-text tokens (e.g., "DEL" -> "Delete", "." -> "Decimal point"). Also apply the standard suite of interaction classes (`rounded-2xl touch-manipulation active:scale-95 focus-visible:ring-2 focus-visible:ring-primary focus:outline-none`) to ensure keyboard users and mobile users get expected UX feedback.
