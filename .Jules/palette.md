## 2024-05-24 - Accessibility improvements on Keypad
**Learning:** Found that the Keypad component (rendering dynamic numeric and action keys) was missing core visual tactile feedback mechanisms (like `active:scale-95`, `touch-manipulation`) and `aria-label` attributes for icon-only action buttons ('DEL' and '.'). The `DEL` and `.` buttons are vital interactive elements but were rendered without screen-reader compliant labeling in the map function. Additionally, `focus-visible` styles are essential here to support hardware keyboard navigation when typing amounts.
**Action:** Always provide explicit `aria-label`s when mapping an array of keys that includes non-alphanumeric icon buttons, and enforce physical tactile feedback classes (`touch-manipulation`, `active:scale-95`) on highly interactive custom touch interfaces like a keypad. Added `focus-visible:ring-2 focus-visible:ring-primary focus:outline-none` for keyboard support.
