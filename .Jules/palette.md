## 2024-05-18 - Keypad Interaction Styles and Accessibility Labeling
**Learning:** Found that custom numeric keypads (`Keypad.tsx`) need specific ARIA labels for non-alphanumeric keys like `DEL` or `.` which otherwise rely purely on visual icons or symbol conventions that aren't screen-reader friendly. Additionally, standard button interaction classes (like active scaling and focus rings) are crucial for keypad components to ensure mobile tactile responsiveness and keyboard navigability.
**Action:** Always map complex or non-alphabetic keys in keypad grids to explicitly descriptive `aria-label`s (e.g., `DEL` -> "Delete") and ensure a full set of interaction utility classes (`active:scale-95`, `focus-visible:ring-2`, etc.) are consistently applied to interactive elements.
