## 2024-05-24 - [Keypad and Large Button Accessibility]
**Learning:** Custom interactive elements, like custom keypads (`Keypad.tsx`) and large action buttons in the transaction flow (`StepAmount.tsx`), often lack standard button semantics like scaling on press (`active:scale-95`), proper touch area semantics (`touch-manipulation`), and screen reader context (`aria-label`) for non-text keys/icons even if they technically use `<button>` tags.
**Action:** When implementing or updating custom interactive components like large touch targets and keypads, always explicitly include full interaction state classes (`active:scale-95`, `focus-visible:ring-2`, `focus:outline-none`, `touch-manipulation`) and verify `aria-label` exists for icon-only components (e.g. "Delete" or "." buttons).
