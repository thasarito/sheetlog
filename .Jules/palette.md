
## 2025-03-22 - Keypad interaction classes and ARIA labels
**Learning:** Standard interaction patterns for buttons such as keypad buttons should include appropriate styles for border-radius (`rounded-2xl`), tactile feedback (`active:scale-95`), mobile responsiveness (`touch-manipulation`), keyboard focus (`focus-visible:ring-2 focus-visible:ring-primary focus:outline-none`), and informative labels for screen readers (`aria-label`).
**Action:** Consistently use these classes and `aria-label` attributes for custom button elements that are used for interactivity in future implementations.
