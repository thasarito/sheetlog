## 2024-05-15 - Interactive Keypad Enhancements
**Learning:** Custom interactive elements like number pads require explicit visual feedback (like active scaling and focus rings) and descriptive ARIA labels for non-standard keys to provide a robust experience for both touch users and screen readers.
**Action:** Always map generic interaction classes (`active:scale-95`, `focus-visible:ring-2`) and provide clear accessibility descriptions for custom data entry components.
